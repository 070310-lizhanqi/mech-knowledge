## 2. 轴的强度公式（来源 B 第七章）

以下公式由 `equation/*.gif` 连通域位图比对定案；变量定义取该章 `.htm` 正文。

### 2.1 扭转强度（7_3_1.htm，式 7-1 / 7-2）

约束条件（式 7-1）：

$$\tau_T = \frac{T}{W_T} \le [\tau_T] \qquad (t\text{-}27T.gif)$$

抗扭截面模量（实心圆轴）：

$$W_T = \frac{\pi d^{3}}{16} \approx 0.2\,d^{3} \qquad (WT=.gif)$$

设计式（式 7-2，`d=.gif`，223×51，双根号结构）：

$$d \ge \sqrt[3]{\frac{T}{0.2\,[\tau_T]}} = \sqrt[3]{\frac{9550\,P}{0.2\,[\tau_T]\,n}}$$

正文依据（7_3_1.htm.txt:161-179）：
- 𝜏_𝑇 危险截面最大扭剪应力 (MPa)；𝑇 转矩 (N·mm)；𝑊_𝑇 抗扭截面模量 (mm³)；𝑃 功率 (kW)；𝑛 转速 (r/min)；[𝜏_𝑇] 许用扭剪应力，见表 7-2
- 𝐶 由材料和受载决定，见表 7-2；弯矩相对转矩小时 𝐶 取小值、[𝜏_𝑇] 取大值，反之相反
- 算出的 𝑑 一般作为轴受转矩段最细处（轴端）直径；若该轴段有键槽应补偿：同一剖面一个键槽 𝑑 增大 5%，两个键槽增大 10%
- 经验估径：高速输入轴按电机轴径估算（`d==.gif`，形如 𝑑 = (0.36~0.40)·𝑑_电机）；各级低速轴按同级齿轮中心距 𝑎 估算（`d===.gif`，形如 𝑑 = (0.5~0.6)·𝑎）

> ⚠️ **未定案项**：`d=.gif` 分子中的常数位（连通域读出 9/5/5/0/1/0 与第二根号分母 0.2[𝜏_𝑇]𝑛）未能逐位确认，上面写的是按正文「𝑊_𝑇=πd³/16≈0.2d³ 代入式 7-1」反推的等价标准式。若原文为 ∛(9550000·P/(0.2[𝜏_𝑇]·n))，则其与 ∛(9550P/(0.2[𝜏_𝑇]n)) 相差 10³ 倍，**该 GIF 的常数位需再确认**（见 §5 差异记录 D-4）

### 2.2 弯扭合成强度（7_3_2.htm，式 7-3 / 7-4 / 7-5）

当量弯矩：

$$M_{ca} = \sqrt{M^{2} + (\alpha T)^{2}} \qquad (Mca=.gif)$$

强度约束条件一般式（式 7-4）：

$$\sigma_{ca} = \frac{M_{ca}}{W} \le [\sigma_{-1}] \qquad (a\text{-}27ca=.gif)$$

$$\sigma_{ca} = \frac{M_{ca}}{W} \le [\sigma_{0}] \qquad (a\text{-}27ca==.gif)$$

正文依据（7_3_2.htm.txt:161-167）：
- 考虑弯矩与转矩产生的应力性质不同，对转矩乘折合系数 𝛼
- 转矩按**脉动循环** 𝛼 = [0.6]；按**对称循环** 𝛼 = [1.0]（即标准值 0.6 与 1.0）
- 转矩变化规律不清楚按脉动循环处理
- [𝜎_{−1}]、[𝜎_0]、[𝜎_{+1}] 分别为对称循环、脉动循环及静应力状态下的许用应力，见表 7-3

> ⚠️ 正文把 𝛼 的值写成 `[0.6]` / `[1.0]`（带方括号）。方括号在本教材中是「许用」的固定记号，这里疑为排版笔误或「推荐取值」之意，撰写/引用时应写作 𝛼 = 0.6 / 𝛼 = 1.0（见 §5 差异记录 D-3）

### 2.3 轴的疲劳安全系数精确计算（7_3_3.htm，式 7-6 / 7-7 / 7-8）

安全系数约束条件（式 7-6）：

$$S_{ca} = \frac{S_{\sigma} S_{\tau}}{\sqrt{S_{\sigma}^{2} + S_{\tau}^{2}}} \le [S] \qquad (Sca=.gif)$$

受弯矩作用时的安全系数（式 7-7，`Sa-27=.gif`，145×67）：

$$S_{\sigma} = \frac{\sigma_{-1}}{\dfrac{k_{\sigma}}{\varepsilon_{\sigma}\varepsilon_{\alpha}} + \dfrac{\sigma_{a}}{\sigma_{-1}}}$$

受转矩作用时的安全系数（式 7-8，`St-27=.gif`，131×65）：

$$S_{\tau} = \frac{\tau_{-1}}{\dfrac{k_{\tau}}{\varepsilon_{\tau}\varepsilon_{\tau\alpha}} + \dfrac{\tau_{a}}{\tau_{-1}}}$$

应力幅（`S0a-27=.gif` / `S0t-27=.gif`）：

$$\sigma_a = \frac{M}{W} \qquad (\text{弯曲应力幅})$$

$$\tau_a = \frac{T}{W_T} \qquad (\text{扭转应力幅})$$

正文依据（7_3_3.htm.txt:159-177）：
- 按当量弯矩计算未考虑应力集中、轴径尺寸、表面品质对疲劳强度的影响，重要轴需做危险截面疲劳安全系数精确计算
- 𝑆_ca 计算安全系数；[𝑆] 最小许用安全系数，见表 7-4
- [𝑆] 取值：载荷可精确计算且材质均匀 **1.3~1.5**；计算精度较低 **1.5~1.8**；计算精度很低或 d>200mm 更大
- 𝜎_{−1} / 𝜏_{−1} 对称循环疲劳极限，见表 7-1；𝑘_𝜎 / 𝑘_𝜏 有效应力集中系数（附表 7-1~3）；𝜀_𝜎 / 𝜀_𝜏 表面质量系数（附表 7-5~7）；𝜀_α / 𝜀_τα 绝对尺寸系数（附表 7-4）；𝑞_𝜎 / 𝑞_𝜏 平均应力折合应力幅的等效系数（表 7-1）；𝜎_𝑎 / 𝜎_𝑚 弯曲应力幅与平均应力；𝜏_𝑎 / 𝜏_𝑚 扭转应力幅与平均应力
- 表 7-4 最后一行「计算精度很低，材质很不均匀，或尺寸很大的轴 (d>200mm)」的 [𝑆] 值未读到（页面未提供具体数值）

> ⚠️ **未完全定案项**：`Sca=.gif`(143×52)、`Sa-27=.gif`(145×67)、`St-27=.gif`(131×65)、`S0=.gif`(152×52) 的分子分母折合项结构，位图连通域已读但 𝜀/k/𝐾_f 的组合顺序未能 100% 逐字定案。上面按标准教材（濮良贵《机械设计》）形式给出，供撰写时引用；如需逐字确认需再读 `_tmp/cc7.txt` 对应段（Sca 约在第 1650 行之后）

## 3. 螺栓联接公式（来源 B 第十一章）

### 3.1 螺纹参数与螺纹副阻力矩（11_1_2 / 11_1_3）

升角（式 11-1，`tgl-27=.gif`，116×45）：

$$\tan\lambda = \frac{S}{\pi d_2} = \frac{np}{\pi d_2}$$

螺纹副阻力矩（`T1=.gif` / `F-27d2.gif`，111×43）：

$$T_1 = F'\,\frac{d_2}{2}\,\tan(\lambda + \rho_v)$$

### 3.2 受横向载荷的普通螺栓联接（11_2_3.htm）

不滑移条件：$F' \cdot u \cdot z \cdot m \ge K_f \cdot R$

每螺栓所需预紧力（`F-27uzm.gif`，96×25）：

$$F' = \frac{K_f R}{z\,m\,u}$$

正文依据（11_2_3.htm.txt:211-225）：
- 𝑢 接合面间摩擦系数，见表 11-1；𝑧 螺栓个数；𝑚 接合面对数
- 𝐾_𝑓 考虑摩擦传力的可靠性系数，常取 **1.1~1.3**
- M10~M68 普通螺栓摩擦力矩作用相当于使拉伸载荷 𝐹′ 增大 30%，按第四强度理论得当量拉力：𝐹_𝑣 = 1.3𝐹′（`Fv=.gif`，77×28）

### 3.3 受轴向载荷的螺栓联接与相对刚度（11_2_4 / 11_2_5）

螺栓总拉力（`F0=.gif`，133×47）：

$$F_0 = F'' + F$$

其中 𝐹″ 为被联接件压缩量减小至的剩余预紧力，𝐹 为轴向工作载荷。

相对刚度定义（11_2_4.htm.txt:183-213）：

$$\frac{C_1}{C_1 + C_2} \ \text{称螺栓相对刚度}, \qquad \frac{C_2}{C_1 + C_2} = 1 - \frac{C_1}{C_1+C_2} \ \text{称被联接件相对刚度}$$

- 与螺栓及被联接件材料、结构、尺寸和垫片有关，值在 0~1 之间
- 若 𝐶₂ 很大 𝐶₁ 很小则相对刚度趋于零，𝐹_0 ≈ 𝐹′；反之趋于 1，𝐹_0 ≈ 𝐹′ + 𝐹
- 为降低螺栓受力应使相对刚度尽可能小，设计时按表 11-2 查取：
  金属垫片或无垫片 **0.2~0.3**；皮革垫片 **0.7**；铜皮石棉垫片 **0.8**

### 3.4 受拉螺栓强度条件（11_2_6.htm）

约束强度条件（`a-27ca=.gif`，113×49）：

$$\sigma_{ca} = \frac{4 \times 1.3\,F'}{\pi d_1^{2}} \le [\sigma]$$

设计式（`d1=.gif`，95×49）：

$$d_1 \ge \sqrt{\frac{4 \times 1.3\,F_v}{\pi [\sigma]}}$$

正文依据（11_2_6.htm.txt:202-234）：
- 近似把螺栓小径对应剖面视为危险剖面
- 𝐹_𝑣 为螺栓所受当量拉力；[𝜎] 为螺栓联接许用应力，见表 11-5
- 设计方法：先确定类型并算受力最大螺栓的拉力 𝐹_𝑣 或剪力 𝐹_𝑠，按约束强度条件算小径 𝑑₁（或螺栓杆直径 𝑑₀），再查标准得螺栓大径 𝑑

> ⚠️ **定案说明**：`a-27ca=.gif` 分子侧连通域读出 `4` + `𝐹` + `下标 v`，未见独立的 `1.3` 与乘号连通域；分母侧读出 `π d 1 2`（𝑑 的右下标 1 与上标 2 并排，是 𝑑₁² 的标准排法）。即 GIF 中写的是 `4F_v/(πd₁²)`，而 𝐹_𝑣 = 1.3𝐹′ 由正文（`Fv=.gif` = 𝐹_𝑣 = 1.3𝐹′）另行给出，两者等价于 4×1.3𝐹′/(πd₁²)。撰写时按 `4×1.3F′/(πd₁²)` 或 `4F_v/(πd₁²)` 均可，但**不要**写成 `4×1.3F_v/(πd₁²)`（会重复乘 1.3）

### 3.5 铰制孔螺栓（受剪螺栓）联接（11_2_6.htm）

挤压强度条件（`a-27p=.gif`，119×47）：

$$\sigma_p = \frac{F_s}{d_0\,h} \le [\sigma_p]$$

剪切强度条件（`t-27=.gif`，109×49）：

$$\tau = \frac{4 F_s}{\pi d_0^{2}\, m} \le [\tau]$$

## 4. 键联接与花键联接公式（来源 B 第十一章 11_4_4 / 11_4_5）

### 4.1 平键联接（11_4_4.htm）

静联接挤压应力（`a-27p==.gif`，167×41）：

$$\sigma_p = \frac{2T}{d\,k\,l} \le [\sigma_p]$$

动联接压强（`p=.gif`，91×41）：

$$p = \frac{2T}{d\,k\,l} \le [p]$$

变量定义（11_4_4.htm.txt:183-206）：
- 𝜎_𝑝 挤压应力 (MPa)；𝑝 压强 (MPa)；𝑇 转矩 (N·mm)；𝑑 轴直径 (mm)；𝑙 平键接触长度 (mm)
  - A 型 𝑙 = 𝐿 − 𝑏；B 型 𝑙 = 𝐿；C 型 𝑙 = 𝐿 − 0.5𝑏（𝑏 为键宽）
- 𝑘 键与轮毂接触高度，一般 𝑘 ≈ 0.5ℎ；ℎ 平键高度
- [𝜎_𝑝] 许用挤压应力，见表 11-8；[𝑝] 许用压强，见表 11-8
- 双键按 180° 布置时，考虑载荷分布不均匀，强度按 **1.5 个键**计算

失效分析（同页）：键侧面受挤压、截面 a-a 受剪切；可能失效为较弱零件（通常轮毂）工作面压溃（静联接）或磨损（动联接）和键的剪断。对实际材料和标准尺寸，压溃/磨损是主要失效，故通常只做挤压应力（静联接）或压强（动联接）校核。

### 4.2 花键联接（11_4_5.htm）

静联接挤压应力（`a-27p===.gif`，137×45）：

$$\sigma_p = \frac{2T}{\psi\,z\,h\,d_m\,l} \le [\sigma_p]$$

动联接压强（`p==.gif`，117×45）：

$$p = \frac{2T}{\psi\,z\,h\,d_m\,l} \le [p]$$

变量定义（11_4_5.htm.txt:182-197）：
- 𝜓 各齿间载荷分配不均匀系数，视加工精度而定，一般取 **0.7~0.8**
- 𝑧 花键齿数
- ℎ 齿侧面工作高度：矩形花键 ℎ = 0.5(𝐷 − 𝑑)（𝐷/𝑑 为花键轴外径/内径）；渐开线花键 ℎ = 𝑚（𝑚 模数）
- 𝑑_𝑚 花键平均直径 (mm)：矩形花键 𝑑_𝑚 = (𝐷 + 𝑑)/2；渐开线花键 𝑑_𝑚 = 𝑑（𝑑 分度圆直径）
- 𝑙 齿的工作长度 (mm)
- [𝜎_𝑝] 许用挤压应力，见表 11-9；[𝑝] 许用压强，见表 11-9
