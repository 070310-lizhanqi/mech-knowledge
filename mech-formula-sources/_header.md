# 机械设计公式库

> 本文件由 `mech-formula-sources/` 目录下 13 个章节公式清单（`ch02`~`ch15-formulas.md`）与 3 份交叉核对报告（`cross-check-wiki.md`、`cross-check-gearbelt.md`、`cross-check-gearboltkeyshaft.md`）合并、去重整理而成。

## 阅读约定

- 公式的数学表达**逐字保留**来源文件中的写法，未修正符号、系数、指数、上下标、括号、正负号与运算顺序。
- 方括号表示许用值，与教材原文一致：`[\sigma]`、`[S_\sigma]`、`[\sigma_{FP}]`。
- 每条公式包含：名称、逐字 LaTeX、符号表（含义 / 单位）、适用条件、参数取值。
- 来源标注格式：`[来源: 教材chX / 国标 / 习题课 / 维基]`。
  - **教材chX** = 章节公式清单 `chNN-formulas.md`
  - **国标** = GB/T 3480-1997（渐开线圆柱齿轮承载能力）、GB/T 13575.1（带传动）、GB/T 1243（滚子链）等，取自 `cross-check-gearbelt.md` 与 `cross-check-gearboltkeyshaft.md`
  - **习题课** = ME311 第三章习题课 PDF 与 speedreducer.org 网络课程，取自 `cross-check-gearboltkeyshaft.md`
  - **维基** = 中文维基百科相关条目，取自 `cross-check-wiki.md`
- 同一公式在多个来源写法不同时**并列保留**（多条编号或一条内分「写法A / 写法B」），并附「**差异说明**」。
- 来源未给出的公式、数值、符号定义一律不补写；标 `[待核对]` 或「查表（原文未给数值）」。
- 原文已注明的笔误一律照录，并加 `> 注：原文如此，疑为笔误 / 照录未改。`
